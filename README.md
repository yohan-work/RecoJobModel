## Projects

PM, 마케터, 세일즈, 디자이너, 개발자 등 다양한 직군의 실무자들이 업무에 활용할 수 있는 AI 도구를 쉽게 찾고, 비교하고, 학습할 수 있는 플랫폼입니다.

## Key Features

- **직군별 AI 도구 탐색**: 직군별로 분류된 120개 이상의 AI 도구
- **검색 및 필터링**: 키워드, 가격, 난이도별 필터링
- **도구 비교**: 최대 3-4개 도구 동시 비교
- **실무 사용 사례**: 16개의 실제 활용 시나리오
- **추천 시스템**: 직군별 맞춤 추천
